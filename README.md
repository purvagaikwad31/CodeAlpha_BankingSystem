# Banking System – CodeAlpha Internship Task 4

## About
A console-based Banking System developed using C++.
It allows users to create accounts, deposit money, withdraw money,
check account balance, and view transaction history.

## Features
- Create Bank Account
- Deposit Money
- Withdraw Money
- Check Account Balance
- View Transaction History
- Save Account Details
- Store Transaction History
- Input Validation

## Technologies Used
- C++
- File Handling
- Object-Oriented Programming Concepts

## Project Files
- main.cpp
- account.txt
- transactions.txt

## How to Run
1. Open the project in VS Code.
2. Compile main.cpp using a C++ compiler.
3. Run the generated executable.
